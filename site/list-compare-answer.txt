Answer body (usable as-is once the candidate is confirmed)
----------------------------------------------------------
Task: given two unsorted plain-text lists (one string per line), produce three
final lists: only in A, only in B, and in both. Duplicates should not create
duplicate output rows, but their counts should not be lost.

Worked example (synthetic data, the same one used by the tool's fixed tests).

List A (5 lines, one of them blank):

    SKU-A<space>
    001
    SKU-A<space>
    <empty line>
    x

List B (3 lines):

    y
    SKU-A
    1

Result under the rules below:

Only in A (2 unique values):

    001
    x

Only in B (2 unique values):

    y
    1

In both (1 unique value, representative original value taken from A):

    SKU-A<space>

Note the trailing space: A's two occurrences are "SKU-A " (lines 1 and 3), B's
one occurrence is "SKU-A" (line 2). With ASCII-end trimming enabled they share
the comparison key "SKU-A", but the delivered value keeps the original text from
A, and the audit trail keeps B's raw text as well.

Counts:

- A: input lines 5 = blank lines 1 + unique values 3 + duplicate extra rows 1
- B: input lines 3 = blank lines 0 + unique values 3 + duplicate extra rows 0

So "SKU-A " occurs twice in A and once in B; "001" and "1" are two different
values and never merge.

Rules that made these lists (they are the whole answer, not a footnote):

- No pre-sorting is required or performed. Output follows first-seen order.
- Comparison is plain string comparison. No CSV/table/number parsing, no numeric
  conversion: 001 is not 1, A-B is not A B.
- A line that is empty or only ASCII spaces/tabs is a blank line: counted in the
  statistics, never a value. Other Unicode whitespace (for example U+3000) is
  data, not a blank line.
- Optional trimming removes only leading/trailing ASCII spaces and tabs. Optional
  case folding folds only ASCII A-Z to a-z. No Unicode normalization: composed
  and decomposed e-acute stay distinct, full-width characters are not converted.
- Duplicate rows fold into one output value, but every line number, raw text and
  occurrence count is preserved on both sides (that is where the "duplicate extra
  rows" figure comes from).
- Empty input is 0 lines. CRLF, LF and CR all split lines; in a non-empty text a
  final line break adds one trailing blank line.

A standard-library Python version with the same semantics:

    import re

    def compare(a_text, b_text, trim=True, case_sensitive=True):
        def fold(s):
            if not case_sensitive:
                s = ''.join(chr(ord(c) + 32) if 'A' <= c <= 'Z' else c for c in s)
            return s

        def norm(raw):
            return raw.strip(' \t') if trim else raw

        def index(text):
            rows = [] if text == '' else re.split(r'\r\n|\n|\r', text)
            order, items = [], {}
            blanks = 0
            for n, raw in enumerate(rows, 1):
                if raw.strip(' \t') == '':
                    blanks += 1
                    continue
                key = fold(norm(raw))
                if key not in items:
                    items[key] = []
                    order.append(key)
                items[key].append((n, raw))
            return rows, blanks, order, items

        a_rows, a_blanks, a_order, a_items = index(a_text)
        b_rows, b_blanks, b_order, b_items = index(b_text)

        only_a = [a_items[k][0][1] for k in a_order if k not in b_items]
        only_b = [b_items[k][0][1] for k in b_order if k not in a_items]
        common = [a_items[k][0][1] for k in a_order if k in b_items]

        def stats(rows, blanks, items):
            valid = len(rows) - blanks
            return (len(rows), blanks, valid, len(items), valid - len(items))

        return {
            'only_in_a': only_a,
            'only_in_b': only_b,
            'in_both': common,          # representative raw value from A
            'counts': {k: (len(a_items.get(k, [])), len(b_items.get(k, [])))
                       for k in a_order + [k for k in b_order if k not in a_items]},
            'stats_a': stats(a_rows, a_blanks, a_items),
            'stats_b': stats(b_rows, b_blanks, b_items),
        }

Check it on the example (the trailing space is written as an escape):

    r = compare("SKU-A \n001\nSKU-A \n\nx", "y\nSKU-A\n1")
    assert r['only_in_a'] == ['001', 'x']
    assert r['only_in_b'] == ['y', '1']
    assert r['in_both'] == ['SKU-A ']
    assert r['stats_a'] == (5, 1, 4, 3, 1)
    assert r['stats_b'] == (3, 0, 3, 3, 0)

One caution over the usual dict/set one-liners: a plain set difference loses the
occurrence counts and the original text (a set of strings also silently drops
which side's spelling you should hand over). If you only need the values and you
accept losing counts and originals, `set(a) - set(b)` is fine; the code above is
for when the counts and the exact original strings are part of the deliverable.
